# Replacing the portfolio images

The files in `assets/` are placeholders. Replace them with your final images while keeping the same filenames, or update the corresponding paths in `index.html` and `README.md`.

| Portfolio section | Current filename |
| --- | --- |
| Profile photograph | `assets/profile-placeholder.svg` |
| VLM-RS audit | `assets/vlm-rs-audit-placeholder.svg` |
| BEN-DG-10 | `assets/ben-dg-10-placeholder.svg` |
| Blender spatiotemporal research | `assets/blender-time-placeholder.svg` |
| Medical segmentation | `assets/medical-segmentation-placeholder.svg` |
| Satellite imagery evaluation | `assets/satellite-evaluation-placeholder.svg` |
| Small GIS studies | `assets/gis-study-placeholder.svg` |
| Leadership | `assets/leadership-placeholder.svg` |

Recommended formats are WebP, PNG, or JPEG. Use images at least 1200 pixels wide for project sections. For the profile image, use a square photograph at least 500 by 500 pixels.

If you change a filename, update it in both `index.html` and `README.md`.
